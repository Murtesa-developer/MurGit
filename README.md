# MurGit

![Banner](banner.jpeg)

A specialized Android application for managing GitHub SSH keys and monitoring repository activities.

## Original Author
**Murtesa Developer**

## Features
- Securely manage SSH keys.
- Monitor GitHub activities.
- Background service for updates.
- **Auto-Monitoring**: Automatically detects and monitors newly created repositories within seconds.
